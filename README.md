# Tabi Fani landing page
Static site: `index.html`, `styles.css`, `script.js`, `assets/`.

1. Logo: replace `assets/logo.svg` (placeholder) with your real logo. If it's a JPG/PNG, save as `assets/logo.png` and update the 3 `<img src>` + favicon in `index.html`.
2. Requests go to WhatsApp: set `WHATSAPP_NUMBER` in `script.js` (currently a TEST number).
3. Instagram/TikTok: fill `SOCIAL_LINKS` in `script.js`.
4. Deploy: push to GitHub → Settings → Pages → deploy from `main` / root.
